# Gen 3 Co-op (g3_coop)

A two-player co-op mod for [Gen1Recomp](https://github.com/bryanthaboi/gen1recomp)'s
Gen 3 games: two players on their own saves share one overworld, battle
together in doubles, trade, and keep a shared Soul Link run with level caps.

Based on the Pokemon Gen 1 Recompilation Project by BOIS CLUB GAMES, LLC
(https://github.com/bryanthaboi/gen1recomp).

It's the co-op half of the
[Emerald Doubles Soul Link](https://github.com/PandaKisor/emerald-doubles-soullink)
cart, which installs this mod for you. The mod itself is in `g3_coop/` (see its
[README](g3_coop/README.md)); `tests/` holds the headless suites and `DESIGN.md`
the milestones.

Releases carry `g3_coop-<version>.zip`, which the launcher's **MODS** import
screen accepts. The `vanilla` branch is the last version for unmodded
Emerald/FRLG (0.7.2).
